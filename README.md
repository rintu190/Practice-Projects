# Handmade Saree Boutique (Flutter)

A modern mobile Flutter app concept to showcase and sell handmade sarees.

## Features

- Modern Material 3 look and feel
- Saree showcase with artisan and delivery details
- Enquiry and order request form
- Vendor details available on request (bottom sheet)

## Run

```bash
flutter pub get
flutter run
```
